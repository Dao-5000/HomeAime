# AI 微信 📱💬

一个微信风格的 AI 聊天 App：**通讯录里的每个人，都是一个 AI 人设**。点开好友、发消息、看对方"正在输入…"、收回复——就像在用微信，只不过对面是 AI。

**不需要 Mac / Xcode**：用手机 Safari 打开即可使用，还能"添加到主屏幕"变成 App 图标。底层对话由 DeepSeek 提供。

---

## 功能

- 🏠 **六栏导航（SVG 线条图标）**：概览｜人格｜记忆｜生活｜记录｜功能
- 🧠 **AI 自我学习**：AI 持续从你的对话、手帐、晚报、待办、笔记中学习，可一键生成并更新「用户核心档案」，让 TA 越来越懂你
- 📁 **磁盘记忆库**：项目根目录自动创建 `记忆库/` 文件夹——把记忆 .txt 丢进去，App 里「功能 → 磁盘记忆库」可直接浏览、**导入**（一条或 **AI 提取成多条记忆**）、删除；也可把全部伴侣记忆**导出成文件**存到文件夹。记忆存文件、可查找、可备份，AI 记得更久
- ✂️ **AI 文本提取记忆**：记忆存储页「AI 提取」——粘贴任意文本（对话记录/设定/笔记），AI 自动提炼成记忆条目，勾选后存入记忆文件夹，不用再折腾 JSON
- 🧵 **对话历史自动压缩**：聊天超过约 140 条后，旧对话自动被压缩成「对话回顾」记忆摘要存进记忆文件夹，保留最近 20 条完整对话——上下文不爆、AI 记得更久
- 🧠 **多层长期记忆**：瞬时对话记忆 / 每日归档记忆（情绪晚报）/ 核心人格记忆（用户档案）三层架构，记忆不会随上下文丢失
- 📅 **记忆页**：每日情绪晚报时间轴（左侧圆点 + 分页「共 X 天・第 X/X 页」）：日期、情绪分数 0-10 + 标签、主题、带时间戳的事件时间轴、情绪流转链、AI 第一人称内心感想（浅色气泡引用）
- 💞 **亲密度系统**：随聊天动态增长/衰减（0-100，陌生人→灵魂伴侣），AI 自动按亲密度调整说话分寸；长期不联系会缓慢回落
- ⏰ **现实时间感知**：AI 知道现在是清晨/深夜、距上次聊天多久、记得昨日和前日的每日记忆
- 📔 **生活手帐**：自动捕捉对话里的碎片想法并分类归档（灵感/计划/目标/心情），也可手动记一笔
- ☀️ **早报 & 🎁 盲盒任务**：每日自动生成早报 + 随机小任务，给生活一点仪式感
- ✅ **待办管理**：记录待办、到期提醒、勾选完成
- 🧘 **自我觉察**：决策追踪 / 习惯养成（连续打卡天数）/ 时间胶囊（写给未来的自己）
- 🗒️ **记录页**：原始对话记录（按日期筛选）+ 读书笔记/报告
- 💾 **数据备份**：一键导出 / 导入全量 JSON，所有数据归属用户
- 🗂 **人格页**：从零创建 AI 伴侣，亲密度进度条展示
- 📁 **记忆存储**（伴侣资料页 → 记忆存储）：AI 的记忆文件夹，支持手动添加 / **粘贴文本导入** / **文件导入**（.txt/.md）/ 聊天长按「让 TA 记住」，每条可编辑、开关启用、删除，旧记忆库自动迁移
- 📋 **角色卡 JSON 导入**：在「添加伴侣」或「记忆存储 → 角色卡」导入 JSON 角色卡，自动识别 `character_name / relationship / personality / core_memory / dialogue_history`——名字、关系（含亲密度）、性格设定一键填入，核心记忆逐条存入记忆文件夹，**`dialogue_history` 会导入为真实聊天记录**（模型可直接读取、继承对话历史），导入后自动刷新会话
- 🎭 **括号动作描写开关**：资料与设置 → 人性化 →「括号动作描写」。开启时 TA 会输出 `(低头玩手指)` 这类神态动作；关闭时所有 `（）`/`()` 内容会被自动剥除，只留纯对话文本
- ⚙️ 其余能力：多服务商 AI 大脑、人性化打字节奏/表情包/口头禅、主动陪伴（最长间隔+免打扰）、语音输入、图片识别、记忆库上传等

## 快速开始（30 秒跑通）

> **先试水？** 直接在电脑浏览器打开 `http://localhost:3000` 即可——宽屏下会自动变成**微信电脑版的双栏布局**（左栏列表 + 右栏聊天窗口），右键消息可撤回/复制，Enter 发送。

### 前提
- 电脑装有 [Node.js](https://nodejs.org) 18 或更高版本（已确认你机器上有 v24 ✅）
- 手机和电脑连**同一个 Wi-Fi**

### 第一步：填写 DeepSeek API Key（二选一）

**方式 A（推荐，Key 存电脑）**：编辑 `config.json`，把 Key 填进去：
```json
{ "apiKey": "sk-你的真实Key" }
```
> Key 在 [platform.deepseek.com](https://platform.deepseek.com) 注册后创建，价格很便宜。

**方式 B（Key 存手机）**：跳过本步，启动后在 App 的【设置】页直接填写。

> 💡 **想发图片给 AI？**（可选）在 [阿里云百炼](https://bailian.aliyun.com) 开通 DashScope 创建 API-KEY（新用户有免费额度），填到 `config.json` 的 `visionApiKey`（或 App 设置页「视觉模型」），图片消息会由通义千问 qwen-vl 理解。

### 第二步：启动服务器

```bash
node server.js
```
终端会显示类似：
```
iPhone 访问: http://192.168.1.15:3000  ← 手机连同一个 Wi-Fi
```

### 第三步：iPhone 打开

1. 用 Safari 打开终端里那个 `http://电脑IP:3000`
2. 点底部 **分享按钮 → 添加到主屏幕**，桌面就会出现 App 图标，之后点图标直接进入
3. 去【通讯录】选一个好友开聊吧！

> 💡 想用浏览器快速预览？电脑上直接打开 `http://localhost:3000`

## 不想开电脑？用「直连模式」

1. 打开 App → 【设置】→ 连接方式选 **直连模式**
2. 填好 API Key
3. 然后把 `public` 文件夹部署到任意**免费静态网站**（GitHub Pages、Netlify、Cloudflare Pages、Vercel 都行），部署一次永久使用

> ⚠️ 直连模式能否成功取决于 DeepSeek 是否允许浏览器跨域。若发消息提示失败，请切回代理模式（用的时候开电脑即可）。

## JSON 导入格式说明

支持两种 JSON 格式，导入时自动识别：

**① 角色卡格式**（模板见项目根目录 `角色卡模板.json`，可直接复制修改）：
```json
{
  "character_name": "骨子",
  "relationship": "亲密恋人",
  "personality": "傲娇嘴硬心软…",
  "core_memory": ["称呼用户：宝", "…"],
  "dialogue_history": [
    { "role": "user", "content": "在吗" },
    { "role": "assistant", "content": "哼，刚忙完 (假装生气)" }
  ]
}
```
- `role` 兼容：user/me/human/用户 → 你；assistant/ai/bot/model/角色 → TA；也支持 `{ "user": "...", "assistant": "..." }` 成对格式
- `dialogue_history` 会**导入为真实聊天记录**（最多 200 条），模型直接读取、继承历史；`core_memory` 逐条进记忆文件夹

**② 全量备份格式**：App 内「功能 → 数据备份 → 导出」生成的 JSON（含 `version/contacts/conversations/messages/…` 全部数据），导入即完整恢复，兼容旧版本备份（自动迁移）。

## 常见问题

| 问题 | 解决办法 |
|------|---------|
| 手机上打不开地址 | 确认手机和电脑同一 Wi-Fi；Windows 防火墙若弹窗请点"允许"；路由器若开了"AP 隔离"需关闭 |
| 发消息提示"尚未配置 API Key" | 电脑 `config.json` 填 Key 后重启服务器，或在手机设置页填 Key |
| 提示"DeepSeek 返回错误 401" | Key 填错了，去 platform.deepseek.com 检查复制 |
| 提示"无法连接聊天服务器" | 服务器没开 / 网络不通，检查第一步第二步 |
| 直连模式发消息报跨域错误 | DeepSeek 限制了浏览器直连，切回代理模式 |
| 发图片提示需要视觉模型 Key | 到 [阿里云百炼](https://bailian.aliyun.com) 开通 DashScope 拿 Key，填设置页「视觉模型」；图片功能需代理模式 |
| 语音按钮不见了 | iOS Safari 16+ 才有语音识别；旧版本或安卓会隐藏按钮，不影响其他功能 |
| 不想让 AI 主动发消息 | 设置 → 真人感 → 关掉「AI 主动发消息」 |
| 聊天记录没了 | 记录存在浏览器本地，清 Safari 缓存/网站数据会删除；换浏览器 = 换一份记录 |

## 项目结构

```
AI聊天项目/
├── server.js              # 零依赖服务器：托管页面 + DeepSeek 流式代理
├── config.json            # API Key 配置（已 gitignore，勿提交）
├── public/
│   ├── index.html         # 页面骨架
│   ├── css/style.css      # 微信风格样式
│   ├── js/
│   │   ├── personas.js    # 内置 AI 人设
│   │   ├── store.js       # 数据层（本地存储）
│   │   ├── app.js         # 入口 / 工具 / 标签页
│   │   ├── chatlist.js    # 聊天列表
│   │   ├── contacts.js    # 通讯录 + 联系人编辑
│   │   ├── chat.js        # 聊天页 + AI 流式对话（双模式）
│   │   └── settings.js    # 设置页

```
